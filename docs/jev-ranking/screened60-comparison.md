# Screened60: publication protocol and current-UI sensitivity

**Disposition: development evidence; no production GO.** The unchanged native C pack
loses one reference-positive read at the primary K=20 budget against the accepted
publication/domain-allocation baseline. In the separately declared current-UI sensitivity,
native priority ordering improves reference-positive recovery over flat creation order.
Both results are reported; the secondary result does not replace the primary comparator.

The [frame](screened60-frame.md) contains the newest 60 retained screened sources after
frozen exposure exclusions. All 60 remain in every denominator: 16 blind model-proxy
utility positives, 40 negatives and four unresolved. These labels are advisory, not human
truth. The sources are exposed development inventory, not untouched or population data;
screen pass is not certified eligibility. No prompt, label, selection, admission filter or
production behavior changes in this comparison.
